⏺ This is a course scaffold for a Flask-based expense tracker web app (repo
  named "expenseTracking", folder post-MADD suggests a "Modern App Development"
  class). It's structured as a step-by-step student exercise:

  - app.py — Flask app with 3 working routes (landing, register, login pages)
  and 5 placeholder routes explicitly labeled "coming in Step N" (logout,
  profile, add/edit/delete expense).
  - database/db.py — currently just a comment describing what students need to
  build in "Step 1": get_db(), init_db(), seed_db() for a SQLite-backed
  database. Not implemented yet.
  - templates/ — has base.html, landing.html, register.html, login.html (the
  pages that already render).
  - static/ — CSS and JS assets.
  - requirements.txt — Flask, Werkzeug, pytest, pytest-flask.

  So the end goal is a full expense-tracking app with user auth
  (register/login/logout/profile) and CRUD for expenses, but right now only the
  skeleton and static pages exist — no database, no auth logic, and the expense
  CRUD routes are stubs. Want to start on Step 1 (database setup)?
